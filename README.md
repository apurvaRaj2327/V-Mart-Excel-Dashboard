# V Mart Annual Sales Dashboard (2025)

## 📊 Project Overview
This project presents an interactive **Excel dashboard** created to analyze V Mart’s annual sales performance for the year 2025. The dashboard provides key business insights using charts, slicers, and KPIs to support data-driven decision making.

## 🛠 Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Cleaning & Formatting

## 📌 Key Insights
- **Women customers contribute ~69% of total sales**, higher than men.
- **Amazon (35%) and Myntra (23%)** are the top-performing sales channels.
- **Maharashtra, Karnataka, and Uttar Pradesh** are the top 3 revenue-generating states.
- **92% of orders are successfully delivered**, showing strong fulfillment performance.
- Adults form the largest customer age group across both genders.

## 📈 Dashboard Features
- Orders vs Sales trend (monthly)
- Sales distribution by gender
- Order status analysis
- Top 5 states by revenue
- Age vs gender order comparison
- Channel-wise order contribution
- Interactive slicers for Month, Channel, and Category

1. Download the Excel file from this repository.
2. Open it using Microsoft Excel (desktop version recommended).
3. Use slicers to interact with the dashboard and explore insights.
